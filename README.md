# Al-Wājibāt al-Mutaḥattimāt

Interactieve leerstof van **Al-Manārah** — de drie fundamenten, Aṣl ad-Dīn, en de zeven voorwaarden van *Lā ilāha illa Allāh*.

## Live site

**https://1abumohamed.github.io/al-wajibat/**

## Belangrijk: index.html uploaden

De volledige site is één bestand (`index.html`, ca. 760 kB) met daarin alle HTML, CSS en JavaScript.

### Zo upload je hem (20 seconden):

1. Download de file die Grok je gaf (`al-wajibat-fixed.html`).
2. Hernoem hem naar **`index.html`**.
3. Ga naar: https://github.com/1AbuMohamed/al-wajibat
4. Klik **Add file** → **Upload files**
5. Sleep `index.html` erin en commit.

Daarna is de site live op GitHub Pages.
