# Al-Wājibāt · Al-Manārah

Interactieve studiewebsite (Nederlands) bij *De verplichte begrippen voor elke moslim en moslima*.

## Live

https://1abumohamed.github.io/al-wajibat/

## Bestanden in de root

| Bestand | Functie |
|---------|--------|
| `index.html` | Volledige site (upload handmatig als deze te groot is voor de API) |
| `nasab.mp3` | Audio van de nasab van de Profeet صلى الله عليه وسلم |

## Upload

1. Download de nieuwste `index.html` uit de chat
2. In GitHub: **Add file → Upload files** (of bewerk `index.html`)
3. Commit op `main`
4. GitHub Pages publiceert automatisch
