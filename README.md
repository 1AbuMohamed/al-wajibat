# Al-Wājibāt al-Mutaḥattimāt

Interactieve leerstof van **Al-Manārah** — de drie fundamenten, Aṣl ad-Dīn, en de zeven voorwaarden van *Lā ilāha illa Allāh*.

## Openen

**Live site:** https://younes0zero.github.io/al-wajibat/

Of open `index.html` lokaal in Safari / Chrome.

## Inhoud

- Leerstof met Qurʾān-verzen (beluisteren), ḥadīths en bewijzen
- Flashcards, bewijskaarten en checklist
- Oefentoets (30 vragen)

Lessen van Shaykh Abū Muḥammad al-Shāmī ḥafiẓahu Allāh.
